# ADR 0002: Внутрішній брендбук та генератор шпалер (Wallpaper Studio)

## Статус

Прийнято

## Контекст

Команда Vet Crew Hospital та партнерські організації потребують доступу до офіційних векторних активів, кольорової палітри, типографіки та шпалер для робочих станцій без необхідності завантаження важких графічних редакторів або звернення до дизайнера. Водночас ці матеріали не повинні індексуватися пошуковими системами як публічні сторінки клініки.

## Рішення

1. Створити внутрішній маршрут `src/routes/brandbook/+page.svelte` із компонентами в `src/lib/components/brand/`.
2. Захистити маршрут від пошукових систем:
   - `<meta name="robots" content="noindex, nofollow" />` у заголовку сторінки.
   - `Disallow: /brandbook` у `static/robots.txt`.
   - Виключення сторінки з `static/sitemap.xml` та `static/llms.txt`.
3. Впровадити інтерактивну студію шпалер (`WallpaperStudio.svelte`) з можливістю вибору ролей персоналу, пресетів розмірів (ПК 16:9, смартфон 9:16) та експортом у 4K Ultra HD через Canvas API.

## Наслідки

- Повна автономність команди у створенні брендових матеріалів.
- Чистий SEO-профіль публічного домену `vet-crew-hospital.org` без витоку внутрішніх сторінок у видачу Google.
