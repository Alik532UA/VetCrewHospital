# AGENTS.md — VetCrewHospital

> **Спершу прочитай [PROJECT-CONTEXT.md](PROJECT-CONTEXT.md).** Там зафіксовано архітектурні інваріанти за каноном v10: параметри адресації, префікси сховища, SEO-політика, політика безпеки (CSP), обробка помилок та стандарти доступності. Цей файл — практична витримка для щоденної роботи агентів.

---

## 1. Що це за проєкт

Офіційний інтерактивний веб-портал ветеринарного госпіталю **Vet Crew Hospital** (`https://vet-crew-hospital.org/`).

- **Основні функції**: інтерактивні канали зв'язку клініки (телефон `+380 77 501 01 01`, Instagram, локація на Google Maps), динамічне 3D-лого клініки з фізикою нахилу, двостадійний скрол-інтерфейс, внутрішній цифровий брендбук та студія шпалер (Wallpaper Studio з 4K експортом).
- **Стек**: SvelteKit 2 + Svelte 5 (Runes), TypeScript 6, `@sveltejs/adapter-static`, CSS Custom Properties.
- **Хостинг**: GitHub Pages на власному домені `vet-crew-hospital.org` з переадресацією 301 зі старої адреси `alik532ua.github.io/VetCrewHospital/`.

## 2. Ключові архітектурні інваріанти

1. **Svelte 5 Runes (виключно):**
   - Жодного синтаксису Svelte 4 (`let:`, `export let`, `$:`, `<slot>`).
   - Використовувати тільки `$state`, `$state.raw`, `$derived`, `$props`, `$effect`, snippets (`{#snippet ...}`).
2. **Сховище та ізоляція:**
   - Префікси: `vetcrewhospital_` (prod), `vetcrewhospital-dev_` (dev).
   - Пряме звернення до `localStorage` повз узгоджені сервіси заборонено (STORAGE-NAMESPACE-v10).
3. **Безпека (CSP & XSS):**
   - Усі інлайн-скрипти в `src/app.html` автоматично хешуються SHA-256 у `svelte.config.js` з попередньою нормалізацією CRLF -> LF. Інваріант контролює юніт-тест `src/csp-hash.test.ts`.
   - Вставка Schema.org (`VeterinaryCare`) дозволена виключно через компонент `src/lib/components/JsonLd.svelte` та безпечну функцію `jsonLdScript()` (`src/lib/security/jsonLd.ts`), що екранує `<`, `>`, `&` та Unicode-розділювачі.
4. **Захист внутрішнього брендбука:**
   - Сторінка `src/routes/brandbook/+page.svelte` має директиву `<meta name="robots" content="noindex, nofollow" />`.
   - `static/robots.txt` містить `Disallow: /brandbook`.
   - `static/sitemap.xml` та `static/llms.txt` містять виключно публічну інформацію головної сторінки.
5. **Обробка помилок (Error Boundaries):**
   - `src/routes/+layout.svelte` огортає контент у `<svelte:boundary>` із запасним компонентом `src/lib/components/ErrorFallback.svelte`.
   - `src/hooks.client.ts` перехоплює необроблені помилки, логує їх через `logService` та контролює автоматичне перезавантаження застарілих чанків (`chunkMissing`).

## 3. Локальні пастки

| Пастка                       | Що врахувати                                                                                                                                                                                                                         |
| :--------------------------- | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Нормалізація CRLF у CSP**  | На Windows Git може перетворювати закінчення рядків на CRLF. HTML-парсер браузера нормалізує їх у LF до обчислення хеша. Будь-які зміни в `src/app.html` обов'язково перевіряти через `npm run test:unit` (тест `csp-hash.test.ts`). |
| **Контакти клініки**         | Номер: `+380 77 501 01 01` (`tel:+380775010101`). Госпіталь **не** заявляється як 24/7 (відповідно до вимог `llms.txt`).                                                                                                             |
| **Абсолютні шляхи**          | `paths.relative: false` у `svelte.config.js`. Усі лінки й ресурси гідратуються з абсолютними шляхами для стабільності SPA при зміні глибини роутів.                                                                                  |
| **Автоматичний бамп версії** | Husky на pre-commit хуку автоматично запускає `scripts/bump-version.mjs`. Не редагуй версію в `package.json` вручну під час рутинних правок.                                                                                         |

## 4. НЕ РОБИ

- **НЕ** додавай інлайн-скрипти до `src/app.html` без оновлення та перевірки CSP SHA-256 хешів.
- **НЕ** використовуй сторонні важкі UI-бібліотеки; дизайн будується на CSS custom properties та іконках `lucide-svelte`.
- **НЕ** відкривай індексацію маршруту `/brandbook` для пошукових ботів.
- **НЕ** пиши код із небезпечною вставкою сирого HTML або незахищеного JSON у теги `<script>`.
- **НЕ** ламай суворість TypeScript (`strict: true`, `noUncheckedIndexedAccess: true`).
