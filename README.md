# Vet Crew Hospital 🐾

Офіційний інтерактивний веб-портал ветеринарного госпіталю **Vet Crew Hospital**.

## ✨ Огляд проєкту

- 🌀 **Динамічне 3D лого**: інтерактивна фізика нахилу від миші та гіроскопа смартфонів, спекулярний відблиск та дихаюча анімація.
- 📜 **Трирівневий скрол**:
  - *Стан 1*: презентація бренду.
  - *Стан 2*: розгорнуті контакти клініки (телефон, Instagram, Google Maps).
  - *Стан 3*: додаткові налаштування та інструменти (тема, мова, повноекранний режим).
- 🌓 **Теми**: світла та темна теми з плавним переходом.
- 🌐 **Двомовність**: українська (UA) та англійська (EN).
- ⚡ **Технології**: SvelteKit 2, Svelte 5 Runes, TypeScript, adapter-static.

## 🚀 Запуск та розробка

```bash
# Встановлення залежностей
npm install

# Запуск dev-сервера
npm run dev

# Перевірка типів та коду
npm run check

# Аудит залежностей
npm run audit:ci

# Збірка для публікації
npm run build
```
